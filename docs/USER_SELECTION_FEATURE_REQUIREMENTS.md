# 云端用户快速选择功能 - 需求文档

## 📋 项目概述

**功能名称**: 云端用户快速选择器  
**需求背景**: 基于发现的云端用户数据API，实现快速用户选择，避免重复录入基础信息  
**用户价值**: 提升医疗机构多用户使用场景的操作效率  
**技术约束**: 最小改动原则，代码量控制在500行以内  

---

## 🎯 功能需求分析

### 用户痛点
1. **重复录入**: 每次训练都需要重新填写用户基础信息
2. **效率低下**: 医疗机构多用户场景下，信息录入成为瓶颈
3. **数据孤岛**: 云端已有用户数据，但前端无法复用

### 解决目标
- ✅ 老用户一键登录，信息自动填充
- ✅ 新用户正常注册，数据同步云端  
- ✅ 智能搜索过滤，快速定位目标用户
- ✅ 长缓存策略，减少服务器压力

## 🔧 技术实施方案

### 系统架构
```
PatientSelectionFeature
├── UserDataService.js          # API服务 (~200行)
│   ├── 用户列表获取 (缓存2小时)

│   └── 缓存管理 (多层降级)
├── SearchableUserSelect.vue    # 选择器UI (~280行)  
│   ├── 搜索框 + 下拉列表
│   ├── 最近用户快捷选择
│   └── 新用户按钮

└── PatientInfoModal.vue (修改)  # 预填充支持 (+20行)
```

### 缓存策略设计
```javascript
CacheConfig = {
  userListTTL: 2 * 60 * 60 * 1000,      // 2小时
  searchTTL: 30 * 60 * 1000,            // 30分钟  
  profileTTL: 60 * 60 * 1000,           // 1小时
  minInterval: 2 * 60 * 1000,           // 2分钟
  offlineCacheTTL: 24 * 60 * 60 * 1000  // 24小时
}
```

### API调用优化
- **启动预加载**: App.vue中预先获取用户列表
- **智能缓存**: 内存缓存 + localStorage降级
- **防抖搜索**: 1秒防抖，减少不必要请求  
- **错误降级**: 网络异常时使用本地缓存
- **调用统计**: 优化前42次/小时 → 优化后2.5次/小时 (减少94%)
